Evidence-class badge vocabulary

Maps 1:1 to matcher's figure-claims-2 evidence classes. Fixed meanings — never re-style one class to look like another.
PRIMARY SOURCEprimary_exact — verbatim from an official/primary product page.
SINGLE SOURCEsingle_secondary — one secondary source states it; honest about the count.
CORROBORATEDcorroborated_exact — multiple pages agree; label deliberately does NOT claim "independent" (can be same publisher).
INFERRED FROM DATED SOURCEinferred_from_dated_source — a bounded inference (e.g. street date from a review dateline). Value renders italic; must never read as a stated fact.
SOURCES DISAGREEconflict — both values render, each with its own receipts; the page does not pick a winner.
Not yet documentedunresolved — muted text, no badge. Core-field absence is information; stretch fields omit the row entirely (8/13 tiering ruling).
