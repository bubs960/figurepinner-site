Thumbnail hover lab — 3 polish levels

Hover (or keyboard-focus) any row. Every variant is an overlay — the row itself never changes size, so the list never shifts (zero CLS). Animations are transform/opacity only (GPU-composited). A ~170ms hover-intent delay stops the strobe effect while scanning the list. Images progressively sharpen: the 48px thumb shows instantly, a 480px rendition crossfades in.

A — Clean overlay zoom

The thumb blooms into a 190px sharp version anchored to the row. Minimal, quiet, fast. The floor: what every polished app does.

B — Quick-Look card (the price moment)

The zoom is a small floating card: big image + name + live median in gold. Turns the hover into a price-guide moment, not just a bigger picture. (Prices below are sample data.)

C — Holo collector card (B + tilt + foil)

Same card, but it tilts subtly toward your cursor and a gold foil sheen tracks your pointer across it — the carded-figure-under-store-lights feeling. Tilt is capped at ±7° so it stays premium, not gimmicky.

Hygiene engineering baked into all three: overlay never reflows the list (no CLS) · transform/opacity only (compositor-only, no paint storms) · 170ms intent delay via transition-delay (scanning the list doesn't strobe) · large rendition (width=480) fetched only on first hover of that row, cached after · low-res thumb upscales instantly underneath so there is never a blank frame · prefers-reduced-motion collapses everything to a simple fade · touch devices never see it (hover: none media query would gate it in production — tap still navigates).
